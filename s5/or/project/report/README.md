# Operations Research report and presentation

The canonical academic report is [`or-project-report.tex`](or-project-report.tex), compiled as [`or-project-report.pdf`](or-project-report.pdf). Its document class, margins, title/certificate/acknowledgement pages, abstract, contents, figure/table lists, chapter order, running headers, and table/figure treatment follow the supplied [`../coa-project-report-ref.tex`](../coa-project-report-ref.tex). The certificate retains unsigned, unnamed approval fields for the current course.

The report PDF has 23 A4 pages, including front matter. Numerical results come from the saved experiment outputs under [`results/`](results/). Charts are generated by [`build_figures.py`](build_figures.py); its PNG outputs are included in the TeX document. Application screenshots show the quick preset and are separate from the reported experiment results. The browser demonstration URL is [traffic-signal-analysis.pages.dev](https://traffic-signal-analysis.pages.dev/).

The seven-minute presentation includes 5:30 of slides and a 1:30 live website demo. Its canonical source is the eight-frame Beamer deck [`presentation/or-project-presentation.tex`](presentation/or-project-presentation.tex), compiled to [`presentation/or-project-presentation.pdf`](presentation/or-project-presentation.pdf). It follows the supplied standard title-slide layout, with a matching blue title panel and date/title/page footer on each slide. To rebuild it, run XeLaTeX twice from `report/presentation/`. The keyboard-navigable [`presentation/presentation.html`](presentation/presentation.html) remains available as a browser version. Speaker labels and separate speaker-notes files have been removed.

The application includes a separate Toronto data-based preset. It uses the 3,139-vehicle AM peak-hour intersection total recorded at Eglinton Avenue East / Victoria Park Avenue on September 16, 2026. The [count table](https://www.toraffic.ca/data/intersection-counts) is sourced from the City of Toronto Open Data. The preset splits that total equally across the four approach inputs because the summary value is not directional; the equal split and retained 20/60/20 turn probabilities are assumptions. This preset is not part of the report's reference results. The data is from the City of Toronto's [Multimodal Intersection Turning Movement Counts](https://open.toronto.ca/dataset/traffic-volumes-at-intersections-for-all-modes/) and is used under the [Open Government Licence – Toronto](https://open.toronto.ca/open-data-licence/).

To regenerate charts, run `python report/build_figures.py` from the project root, then convert the generated SVG files to PNG at print resolution. This includes [`assets/fig-grid-timing.png`](assets/fig-grid-timing.png), which compares the selected four-second and one-second green allocations. Compile the report TeX file with XeLaTeX or LuaLaTeX. The report sets its main font to the installed Times New Roman family and includes the college emblem and all required chart/screenshot PNG assets in this folder.
