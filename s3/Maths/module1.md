- random variable with a possible values of 0 or 1 is called a Bernoulli random variable- discrete random variable - countably infinite
- continuous random variable
  - all numbers in continuous range or join of disjoint intervals
  - all of them have probability 0

## notations

- p(x) probability mass function evaluated at x
- P(X=x) pmf at x is equal to probability or rv X at specific value x
- $(P(\forall v \in S : X(v) = x))$

## CDF

- $F(x)$ = $P(X \leq x)$ = $\sum_{y:y \leq x} p(y)$
